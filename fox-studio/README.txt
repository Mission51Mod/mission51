Fox Studio
==========

Open fox-studio.exe to create or open a project. fox.exe is the companion
command-line tool used by the editor. Keep both programs in this folder.
CAPABILITIES.txt lists the native workflows and the location generators that
remain unavailable in this public bundle.

The application requires Windows 10 or later, a 64-bit processor and a
graphics driver with Direct3D 12 or Vulkan support. Game-specific operations
read files from your own licensed MGSV: The Phantom Pain installation.

Choose a separate test installation for mod operations. Project files,
extracted game files and your settings belong outside the application folder.
The distribution contains no game assets, CE material or name dictionaries.
Names are generated from the user's installation; nothing is downloaded
automatically.

The first release is unsigned. Verify the download against SHA256SUMS.txt.
Our code is licensed under either MIT or Apache-2.0; both texts are included.
Third-party crate notices and full licence texts are in THIRD_PARTY.txt and
THIRD_PARTY.html.

The portable archive requires no installer. Extract the whole folder before
running it. The optional installer installs per user and requires no admin
rights. Uninstalling removes the application and shortcuts; projects,
settings and extracted game data remain in their selected locations.
