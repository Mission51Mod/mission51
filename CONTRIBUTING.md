# Contributing

For a tool bug, include the version, operating system, steps to reproduce, expected result and actual result. A small synthetic example is more useful than a full game archive.

Do not attach game executables, extracted game assets, encryption keys, private saves, access tokens or Collector's Edition media. Remove personal paths and account details from logs before posting them.

For Rust changes, follow the existing crate boundaries and formatting. Explain the user-visible behavior and include a focused regression test when it proves a meaningful failure. Use the exported snapshot's build instructions; it must work without a private developer checkout.

Gameplay proposals should describe the intended behavior and what would demonstrate it in game. Please distinguish observations from hypotheses about the engine.
