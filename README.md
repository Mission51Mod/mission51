# Mission 51: Kingdom of the Flies

**Eli has Sahelanthropus. Diamond Dogs are coming to take it back.**

We're rebuilding *Metal Gear Solid V*'s unfinished Episode 51 as a playable mission for *The Phantom Pain* on PC: a new island, a battle against Eli's Sahelanthropus, and a chance to take Battle Gear into the field.

## Return to the Kingdom of the Flies

The island is the setting for a battle between Diamond Dogs, XOF and Eli's child soldiers. Infantry, tanks and helicopter reinforcements will fight across it as Snake closes in on Sahelanthropus. Protecting the children is part of the mission: DD and XOF will use nonlethal weapons against them, while fighting each other with lethal force.

## Take command of Battle Gear

Battle Gear is being built as a playable machine with its own movement, weapons and controls. Its hover movement and changing combat posture draw on the original game model and cutscene animation data.

**In development.** The first playable mission build and release date have not been announced. See [project status](docs/STATUS.md) for current progress.

## Fox Studio source

Fox Studio is our Rust editor and toolset for Fox Engine modding. The [0.1.0 source](fox-studio/) includes project configuration, asset previews, archive operations and mod workflows. Animation editing is in development for a later version.

Start with the [getting-started guide](docs/GETTING_STARTED.md), [build instructions](fox-studio/README-SOURCE.txt) and [tool capabilities](fox-studio/CAPABILITIES.txt). This repository contains our tooling source; you will need your own game files.
